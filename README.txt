LIFE OS Health — Android Chrome PWA版

1. 旧PC版の「設定・バックアップ」からJSONを書き出して保管。
2. このフォルダの内容すべてをHTTPSの静的サイトに公開（GitHub Pages等）。
3. Android Chromeで公開URLを開き、「アプリをインストール」または「ホーム画面に追加」。
4. アプリ内「設定・バックアップ」でJSONを復元。
5. 食事・筋トレ・身体の記録を確認するまで旧PC版を削除しない。

注意：index.htmlをfile://で開くだけではPWAとしてインストールできません。
記録は端末のブラウザ保存領域にあります。公開URLのドメイン変更やサイトデータ削除では失われることがあります。定期的にJSONをバックアップしてください。
更新時は同じURL・ドメインを維持してください。
